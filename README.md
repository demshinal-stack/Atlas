# Сервер семейного обмена

Нужен только для того, чтобы поездки прилетали сами, без пересылки файлов.
Без него приложение работает полностью — обмен идёт файлом через мессенджер.

## Что сервер знает о вас

Ничего. На него приходит два поля: отпечаток ключа группы (по нему нельзя
восстановить ключ) и зашифрованный кусок данных. Расшифровать его может
только тот, у кого есть двенадцать слов вашей группы.

## Как поднять

1. Зайдите на dash.cloudflare.com, раздел Workers & Pages.
2. Create → Worker, вставьте содержимое `worker.js`, нажмите Deploy.
3. Settings → Variables → KV Namespace Bindings: создайте хранилище
   и привяжите под именем `ATLAS`.
4. Скопируйте адрес вида `https://имя.ваш-домен.workers.dev`.
5. В приложении: Профиль → Семья → поле «Сервер» → вставьте адрес →
   «Сохранить адрес». Переключатель «Через сервер» станет доступен.

Бесплатного тарифа хватает с огромным запасом: семья из пяти человек
расходует меньше сотой доли дневного лимита.

## Если сервер отключить

Приложение заметит это само: переключатель «Через сервер» станет
недоступен, обмен вернётся к файлам. Данные никуда не денутся.
